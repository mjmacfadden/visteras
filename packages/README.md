# packages/

Shared libraries used by Visteras apps (Studio, Vector, and others).

| Package | Purpose |
|---------|---------|
| [`fonts`](./fonts/) | `@visteras/fonts` — shared typeface catalog + browser font loader |
| [`ui`](./ui/) | `@visteras/ui` — shared UI kit (toast, confirm/Unsaved Changes dialog, file helper, menu/tab tokens); accent stays per app |

Cross-app document compatibility remains intentionally out of scope.
